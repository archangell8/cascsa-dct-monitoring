# Monitoring DCT: Snowflake Source Objects

This repository contains the source code for the monitoring and alerting scripts used in the Digital Control Tower (DCT) project to ensure: (i) data consistency and operational health between Snowflake and its respective source systems; (ii) data consistency in the results generated by the project's transformations ([dbt repository](https://git.cglcloud.com/MinervaEngineering/miw-casc-digital-control-tower-trns)).

## Monitoring Types

- **Ingestion Delay:**
  Compares source and Snowflake tables, writing results into monitoring tables in Snowflake. Optionally, sends alerts via Teams and email if the `--send-alerts` flag is used.
- **Ingestion Tasks:**
  Monitors the status of Snowflake scheduled tasks. Sends email and Teams alerts if `--send-alerts` is provided.
- **Ingestion Audit:**
  Checks audit dates between source and Snowflake tables. Sends email and Teams alerts if `--send-alerts` is provided.
- **Transform**:
  Monitor crutial data quality on snowflake. Sends email alerts if `--send-alerts` is provided.

**Note:** All monitored objects were configured in assets/configs/tables.yml and assets/configs/tasks.yml.

## Results in Snowflake

The **ingestion-delay** monitoring writes results to the following tables:

- **JDE:** `casc_digital_control_tower_{{ env }}.digital_control_tower_trns.tab_monitoring_count_diff_jde`
- **PSCFL:** `casc_digital_control_tower_{{ env }}.digital_control_tower_trns.tab_monitoring_count_diff_pscfl`
- **RDS:** `casc_digital_control_tower_{{ env }}.digital_control_tower_trns.tab_monitoring_count_diff_rds`
- **FTS:** `casc_digital_control_tower_{{ env }}.digital_control_tower_trns.tab_monitoring_count_diff_fts`
- **JDE_FULL:** `casc_digital_control_tower_{{ env }}.digital_control_tower_trns.tab_monitoring_count_diff_jde_full`
- **CTMS:** `casc_digital_control_tower_{{ env }}.digital_control_tower_trns.tab_monitoring_count_diff_ctms`

> **Note:**
> Only the **ingestion-delay** monitoring writes results into Snowflake tables.
> The **ingestion-tasks** and **ingestion-audit** monitorings only send alerts if the `--send-alerts` flag is provided, and do **not** write monitoring results to Snowflake.

## Prerequisites
Before you begin, ensure you have met the following requirements:

- **Python**: Version 3.8 or higher.
- **Pip**: Python package installer. It usually comes with Python.
- **Java**: Java to create JDBC connections with the sources.
- **Git**: To clone the repository.

## Installation / Setup Enviroment
1. Clone the repository:
    ```sh
    $ git clone https://git.cglcloud.com/FranciscoJunior/monitoring-dct-minerva-objects.git
    ```
2. Navigate to the project directory:
    ```sh
    $ cd monitoring-dct-minerva-objects
    ```

3. Create python virtual enviroment:
    ```sh
    $ python -m venv venv
    ```

4. Active virtual enviroment:
    ```sh
    # Windows system
    $ .\venv\Scripts\activate
    ```

    ```sh
    # Unix system
    $ source .\venv\bin\activate
    ```

5. Update Pip:
    ```sh
    $ python -m pip install --upgrade pip
    ```

6. Install dependencies
    ```sh
    $ pip install -r .\requirements.txt
    ```

7. Configure enviroment variables
    ```sh
    $ cp .\.env.sample .\.env
    ```

    ```sh
    # Edit the .\.env file with your credentials
    $ vi .\.env

    # If you are using windows, please edit the file manually
    ```

## Running Monitoring

To execute the script, ensure your Python virtual environment is active and the `.env` file is configured.

### General usage

The script uses subcommands for the desired monitoring type.
You **must** specify the environment with `--env`, and choose one of the monitoring types:

- `ingestion-delay`
- `ingestion-tasks`
- `ingestion-audit`
- `transform`

Each subcommand may have additional options as described below.

---

### 1. Ingestion Delay Monitoring

Monitor the ingestion delay for a specific source (default: `jde`):

```shell
python main.py --env dev ingestion-delay --source jde
# or for production
python main.py --env prd ingestion-delay --source jde
```

You can also select other sources: `jde_full`, `pscfl`, `fts`, `rds`, `ctms`:

```shell
python main.py --env dev ingestion-delay --source pscfl
```

To send alerts to Teams and Email:

```shell
python main.py --env dev ingestion-delay --source jde --send-alerts
```

---

### 2. Ingestion Tasks Monitoring

Monitor the status of Snowflake scheduled tasks:

```shell
python main.py --env dev ingestion-tasks
# or for production
python main.py --env prd ingestion-tasks
```

To send alerts to Teams and Email:

```shell
python main.py --env dev ingestion-tasks --send-alerts
```

---

### 3. Ingestion Audit Date Monitoring

Monitor the audit date between source and Snowflake:

```shell
python main.py --env dev ingestion-audit --source jde
# Other sources: jde_full, pscfl, fts, rds, ctms
python main.py --env dev ingestion-audit --source pscfl
```

To send alerts to Teams and Email:

```shell
python main.py --env dev ingestion-audit --source jde --send-alerts
```

---

### 4. Transform Monitoring

Monitor crutial data quality on Snowflake:

To run all transformation monitoring use `--group all`:

```shell
python main.py --env dev transform --group all
```
You can also select especific group: `masterdata`, `shipment`, `duplicates`:

```shell
python main.py --env dev transform --group masterdata
```

To send alerts to Email:

```shell
python main.py --env dev transform --group all --send-alerts
```
